# chesseiy .. User Stories

## Overview

This document defines the user stories for chesseiy, organized by functional area. Each story describes a distinct user need and the value it delivers.

## Conventions

- **Format:** As a [role], I want [capability], so that [benefit].
- **Tags:** Release scope (**MVP** / **v1** / **v2**) · Phase (**P#**) .. see `phases.md` for phase definitions.
- **Identifiers:** Each story is assigned a stable ID (`US-01` ... `US-29`) for referencing in specifications, tickets, and tests.

## A. Getting started

- **US-01** .. *MVP · P2* .. As a **beginner**, I want to play without signing up, so that I can try the site in seconds.
- **US-02** .. *MVP · P2* .. As a **visitor**, I want to sign up with email or Google, so that my games and rating are saved.
- **US-03** .. *MVP · P2* .. As a **guest**, I want to upgrade to a full account and keep my games, so that I don't lose my history.
- **US-04** .. *MVP · P2* .. As a **player**, I want to reset my password by email, so that I can get back into my account.
- **US-05** .. *v1 · P3* .. As an **Arabic speaker**, I want the whole site in Arabic with right-to-left layout, so that I understand everything easily.

## B. Playing

- **US-06** .. *MVP · P4* .. As a **casual player**, I want to play the computer at friendly levels like "Beginner Bot", so that I can practice without pressure.
- **US-07** .. *MVP · P5* .. As a **player**, I want to invite a friend with a link, so that we can play right away.
- **US-08** .. *MVP · P7* .. As a **player**, I want quick matchmaking by time control (like 3+0 or 10+0), so that I get a game in seconds.
- **US-09** .. *MVP · P6* .. As a **serious player**, I want accurate server-side clocks, so that the game is fair even with lag.
- **US-10** .. *MVP · P6* .. As a **player**, I want the game to continue if I refresh or my internet drops, so that I don't lose unfairly.
- **US-11** .. *MVP · P6* .. As a **player**, I want to resign, offer a draw, or ask for a rematch, so that I control how the game ends.
- **US-12** .. *v1 · P5* .. As a **player**, I want illegal moves to be rejected by the server, so that nobody can cheat by editing the page.

## C. Ratings and beginner protection

- **US-13** .. *v1 · P7* .. As a **new player**, I want placement games with a hidden rating, so that I am not crushed by much stronger players.
- **US-14** .. *v1 · P7* .. As a **player**, I want a fair rating (Glicko-2) that updates after rated games, so that my number really reflects my level.
- **US-15** .. *v1 · P8* .. As a **player**, I want to see my rating graph and game history on my profile, so that I can see my progress.
- **US-16** .. *v1 · P8* .. As a **player**, I want a league like Bronze or Gold with a progress bar, so that my rating feels clear and motivating.
- **US-17** .. *v1 · P8* .. As a **player**, I want a season ladder and leaderboards (global, country, friends, most improved), so that I always have something new to chase.

## D. Learning and improving

- **US-18** .. *v1 · P10* .. As an **improver**, I want a plain-language review of my game with accuracy and key mistakes, so that I understand what went wrong.
- **US-19** .. *MVP · P4* .. As a **player**, I want an analysis board where I can import PGN/FEN and see engine lines, so that I can study any position.
- **US-20** .. *v1 · P11* .. As a **player**, I want puzzles near my level, with themes like fork or pin, so that I can train tactics.
- **US-21** .. *v2 · P11* .. As a **beginner**, I want short interactive lessons (how pieces move, checkmates), so that I can learn from zero.
- **US-22** .. *v1 · P11* .. As a **busy player**, I want a daily goal and a streak with a free streak freeze, so that I have a reason to come back without stress.
- **US-23** .. *v1 · P11* .. As a **player**, I want achievements and weekly quests, so that I enjoy small rewards for trying new things.

## E. Community

- **US-24** .. *v1 · P12* .. As a **player**, I want to add friends, see who is online, and challenge them in one tap, so that playing together is easy.
- **US-25** .. *v2 · P15* .. As a **club organizer**, I want to create a club and run a tournament (arena or Swiss), including beginner-only events, so that my group can compete fairly.
- **US-26** .. *v2 · P15* .. As a **spectator**, I want to watch live games, so that I can learn from stronger players.

## F. Safety and fairness

- **US-27** .. *v1 · P12* .. As a **parent**, I want a family mode with quick-phrase chat only and no DMs from strangers, so that my child is safe.
- **US-28** .. *v1 · P12* .. As a **player**, I want to report abuse or cheating and see the status of my report, so that I trust the site is fair.
- **US-29** .. *v2 · P16* .. As a **sanctioned player**, I want to see the reason category and appeal the decision, so that I can understand the outcome and have it reviewed fairly.
